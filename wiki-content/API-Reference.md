> Эта страница служит справочником для фронтенд-разработчиков и интеграторов, документируя доступные серверные маршруты и требования к авторизации.

# Справочник API

Серверный API построен по принципам REST. Все запросы, требующие авторизации, ожидают заголовок:  
`Authorization: Bearer <JWT_TOKEN>`.

---

## 1. Системные маршруты и мониторинг

| Метод | Маршрут | Авторизация | Описание |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/health` | Нет | Проверка состояния сервиса, доступности PostgreSQL, времени работы и расхода памяти. |
| `POST` | `/api/log-error` | Нет | Приём логов клиентских сбоев UI и ошибок Service Worker. |
| `POST` | `/api/admin/clear-all-data` | Нет (Dev) | Очистка таблиц базы данных на тестовых и стейджинг стендах. |

---

## 2. Модуль авторизации и профилей (`/api/auth`)

| Метод | Маршрут | Авторизация | Описание |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/auth/register` | Нет | Регистрация нового аккаунта (логин от 3 символов, пароль от 6 символов). |
| `POST` | `/api/auth/login` | Нет | Аутентификация пользователя и выдача подписанного JWT-токена. |
| `GET` | `/api/auth/users` | Нет | Каталог пользователей для поиска партнёра. |
| `GET` | `/api/auth/user/:login` | Да | Получение публичной информации и профиля пользователя. |
| `POST` | `/api/auth/update-profile` | Да | Редактирование профиля (имя, аватар, дата начала отношений, город, языки любви). |
| `POST` | `/api/auth/change-password` | Да | Безопасная смена пароля с проверкой старого пароля. |
| `POST` | `/api/auth/reset-password` | Нет | Восстановление доступа к учётной записи. |
| `POST` | `/api/auth/sync` | Нет | Быстрая синхронизация состояния аккаунта при холодном старте. |

---

## 3. Модуль связывания пары (`/api/pair`)

| Метод | Маршрут | Авторизация | Описание |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/pair/request` | Да | Отправка заявки на привязку по логину или короткому коду `LOOP-XXXX`. |
| `POST` | `/api/pair/accept` | Да | Принятие входящей заявки (атомарное создание пары в транзакции). |
| `POST` | `/api/pair/reject` | Да | Отклонение входящей заявки. |
| `POST` | `/api/pair/disconnect` | Да | Двухшаговый разрыв пары с переводом истории в архивный режим. |
| `GET` | `/api/pair/status/:login` | Да | Получение текущего статуса пары и списка активных заявок. |

## 4. Модуль данных пары (`/api/couple`)

| Метод | Маршрут | Авторизация | Описание |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/couple/sync` | Да | Сохранение прогресса пары (тесты, вопросы дня, цели) с серверным пересчётом XP. |
| `GET` | `/api/couple/data/:key` | Да | Загрузка общего документа пары по составному ключу пары. |
| `GET` | `/api/couple/data/:login1/:login2` | Да | Получение совместных данных по логинам обоих участников. |

## 5. Модуль мгновенных касаний и Push (`/api/couple`, `/api/push`)

| Метод | Маршрут | Авторизация | Описание |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/couple/touch` | Да | Отправка быстрого эмоционального знака («Обнять», «Скучаю», «Поцелуй»). |
| `GET` | `/api/couple/touches/:login` | Да | Получение списка последних полученных касаний. |
| `GET` | `/api/couple/events-stream/:login` | Да | Подключение к постоянному Server-Sent Events (SSE) каналу доставки событий. |
| `POST` | `/api/push/subscribe` | Да | Регистрация Web Push подписки браузера пользователя. |
| `POST` | `/api/push/send-test` | Да | Проверочная отправка тестового браузерного push-уведомления. |

## 6. Модуль чата и ИИ-психолога «Сова» (`/api/chat`, `/api/ai`)

| Метод | Маршрут | Авторизация | Описание |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/chat/messages/:coupleId` | Да | История совместного чата пары в режиме диалога «Вместе». |
| `POST` | `/api/chat/messages` | Да | Отправка сообщения в совместный чат пары. |
| `GET` | `/api/ai/messages/:login` | Да | Загрузка личной истории приватных бесед с Совой (режим «Соло»). |
| `POST` | `/api/ai/chat` | Да | Запрос к ИИ-психологу (структурированный ответ: Взгляд, Практика, Вопрос). |
| `POST` | `/api/ai/generate-report` | Да | Формирование детального ИИ-отчёта по завершённым тестам совместимости. |
| `POST` | `/api/ai/date-idea` | Да | Генерация персонализированных сценариев свиданий. |
