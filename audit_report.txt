## Аудит нереализованного функционала (Декоративные элементы без бэкенда)

В ходе обследования кодовой базы (до применения новых скиллов) найдены следующие интерактивные функции, которые обновляют данные только в React State или LocalStorage (через функции вроде `createDateInvite`, `addFeedItem`, `completeChallenge`), но **не отправляют данные на сервер (PostgreSQL/Dual-Storage)**. В случае перезахода с другого устройства или отправки партнеру — данные не синхронизируются.

1. **Конструктор свиданий (DatesView.tsx) / Колесо свиданий**: 
   - `handleSendInvite` вызывает `createDateInvite` внутри `CoupleContext.tsx`.
   - Сама `createDateInvite` только мутирует `setDateInvites((prev) => ...)` (React State/Local), но **не содержит** вызова `apiFetch('/api/date/invite', ...)` для сохранения в БД.
   - *Результат:* Партнёр не увидит приглашение, если откроет приложение с другого устройства.

2. **Действия с вызовами/челленджами (UsView.tsx / TimeCapsuleSection.tsx)**:
   - Обновление бейджей (например, челленджей) обновляется только в стейте, нет API для синхронизации.
   - Книга заботы / Идеи сохраняют ответы только локально. Запросы вроде `addFeedItem` также не синхронизируют feed в БД.

3. **Тесты и Опросы (TestsView.tsx / DashboardView.tsx - Question of the Day)**:
   - При завершении теста или отправке ответа в Вопрос дня (`handleAnswerSubmit` в DashboardView), контекст обновляет локальные данные, но не отправляет явный POST-запрос с прогрессом теста в базу, полагаясь либо на периодический глобальный sync (который не гарантирует мгновенной доставки), либо вообще не синхронизируясь напрямую с `coupleData` в бэкенде.

4. **Индикатор/бейдж на вкладке Свидания**:
   - Работает на основе несинхронизированных (локальных) `dateInvites`. Значит, бейдж 1 появляется только у того, кто отправил (в локальном стейте), но не доставляется партнеру через реалтайм/БД.

**Вывод:**
Пока что большинство фич вне P0 работают как локальный прототип (Single Player), несмотря на наличие SQL-базы, которая на данный момент используется полноценно только для юзеров, пар, запросов и чата (AI).
