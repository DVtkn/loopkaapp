# База знаний Loop

**Loop** — это бережное мобильное веб-приложение для пар, помогающее глубже узнать друг друга, проходить психологические тесты, подсвечивать сильные стороны отношений и мягко решать разногласия с поддержкой ИИ-психолога «Сова». Сервис соединяет научные методики семейной терапии (Готтман, 5 языков любви, теория привязанности, ЭФТ) с лёгкими ежедневными практиками внимания.
