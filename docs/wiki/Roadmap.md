# План развития проекта (Roadmap)

В данном документе зафиксированы открытые технические задачи и направления развития функционала. Содержимое синхронизировано с разделом [Roadmap в PRD.md](../PRD.md#открытые-пункты-и-план-реализации-roadmap).

---

## 1. Ближайшие технические ворота (Pre-Production Gates)

### Шаг 1. Live Groq AI Verification
- **Цель**: Перед первым публичным релизом провести контрольный прогон эндпоинта `/api/ai/chat` с реальным ключом `GROQ_API_KEY`.
- **Критерии приёмки**:
  - Успешный ответ модели `llama-3.3-70b-versatile` при времени отклика менее 10 секунд.
  - Корректный парсинг всех трёх структурных блоков Совы (*Взгляд психолога*, *Практика / Готовая фраза*, *Вопрос для вас*).
  - Безупречное переключение на локальный `psychologyEngine.ts` при искусственном разрыве соединения.
  - Фиксация отчёта в `test-reports/live-groq-run.log`.

### Шаг 2. Интеграция E2E тестов в CI/CD
- **Цель**: Автоматизировать запуск сквозных пользовательских тестов `e2e/loop.spec.ts` (Playwright) в GitHub Actions.
- **Критерии приёмки**:
  - Прогон в контейнере Chromium при каждом Pull Request.
  - Проверка двухпользовательских сценариев: связывание пары, прохождение теста, отображение ответов на вопрос дня.
  - Нулевое количество ложных срабатываний из-за сетевых задержек.

### Шаг 3. Комплексная верификация Web Push и медиа-архива
- **Цель**: Покрыть автоматическими проверками подсистему браузерных push-уведомлений и загрузки фотографий.
- **Критерии приёмки**:
  - Тестирование генерации VAPID-подписок и отписки устройств.
  - Проверка ограничений на размер и сжатие изображений перед записью в PostgreSQL (`BYTEA`).

## 2. Продуктовые инициативы следующего этапа

### Расширение психологической базы
- Добавление авторских колод карточек для раздела **Deep Talk** (темы: совместное будущее, доверие, финансы в паре, сексуальность и близость).
- Внедрение новых коротких рефлексивных мини-тестов (шкала стресса пары, эмоциональное выгорание в быту).

### Офлайн-устойчивость (PWA Offline First)
- Расширение Service Worker для кэширования библиотеки вопросов и истории пройденных тестов.
- Возможность чтения капсулы времени и ответов партнёра без активного интернет-соединения.

### Виджеты и нативные интеграции
- Создание мини-виджетов для мобильных экранов iOS / Android (отправка касания в 1 клик с домашнего экрана телефона).
- Расширение звуковой и тактильной обратной связи при получении мгновенных касаний.
