# Быстрый старт для разработчика

Данное руководство позволит развернуть проект **Loop** на локальной машине за 5 минут.

---

## 1. Системные требования

- **Node.js**: версия `18.x` или выше (рекомендуется `20.x LTS`).
- **Менеджер пакетов**: `npm` (версия 9+) или `bun`.
- **Git**: для клонирования и управления ветками.

---

## 2. Пошаговая установка

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/your-org/loop.git
cd loop
```

### Шаг 2. Установка зависимостей

```bash
npm install
```

### Шаг 3. Настройка переменных окружения

Скопируйте пример файла конфигурации:

```bash
cp .env.example .env
```

Откройте созданный файл `.env` в текстовом редакторе и настройте параметры.

> **Важно**: Подробные правила назначения и генерации ключей описаны на странице [Безопасность (Security)](Security) и в файле [SECURITY.md](../SECURITY.md).

Минимальный набор для локального запуска:

```env
# Окружение (development / production)
NODE_ENV=development

# Порт приложения (контейнер и dev-сервер)
PORT=3000

# Секрет подписи JWT токенов (сгенерируйте произвольную длинную строку для dev)
JWT_SECRET=dev_jwt_secret_loop_local_development_only_123456

# Подключение к PostgreSQL (опционально для dev, обязательно для prod)
# DATABASE_URL=postgresql://user:password@ep-sample.neon.tech/loop?sslmode=require

# Ключ Groq API для реальных ответов ИИ-психолога Совы (опционально)
# GROQ_API_KEY=gsk_...
```

---

## 3. Особенности поведения Dev vs Production

Перед запуском важно понимать разницу между окружениями:

| Параметр | Development (`NODE_ENV=development`) | Production (`NODE_ENV=production`) |
| :--- | :--- | :--- |
| **База данных** | Если `DATABASE_URL` не задан, сервер автоматически использует локальный JSON-файл `/data/db_store.json`. Настройка облачной БД не обязательна для старта. | Требуется валидный `DATABASE_URL` (Neon PostgreSQL). Файловый режим отключён; при сбое подключения сервер падает с фатальной ошибкой (Fail-Fast). |
| **JWT_SECRET** | Допускается локальный секрет из `.env`. | Обязателен уникальный 64-символьный криптостойкий ключ. |
| **Сборка фронтенда** | Vite работает в режиме middleware с горячей подгрузкой модулей. | Сервер отдаёт скомпилированную статику из каталога `/dist`. |

---

## 4. Запуск приложения

Запустите сервер в режиме разработки:

```bash
npm run dev
```

Сервер станет доступен по адресу: `http://localhost:3000`

---

## 5. Запуск тестов и линтера

В репозитории накоплен набор интеграционных скриптов, верифицирующих критические пути:

```bash
# 1. Проверка типов TypeScript
npm run lint

# 2. Полный интеграционный прогон (регистрация, пара, данные, чат, касания)
npx tsx tests/run-integration-full.ts

# 3. Проверка строгого падения в продакшене без DATABASE_URL (Fail-Fast тест)
npx tsx tests/test-prod-db-failfast.ts

# 4. Проверка корректного переключения на JSON fallback в dev-режиме
npx tsx tests/test-dev-db-fallback.ts

# 5. Проверка защиты от инъекции уровня пары (Security Strip тест)
npx tsx tests/test-sync-vuln.ts

# 6. Проверка production-сборки проекта
npm run build
```
